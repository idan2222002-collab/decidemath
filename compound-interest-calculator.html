Compound interest calculator

Project how a starting balance and optional regular contributions can grow, with the compounding frequency you choose.

How to use: enter a starting amount, rate, years, optional contribution, and compounding frequency. Future value and interest earned update as you type.

Compound interest formula

Future value = P(1 + r/n)nt + PMT × [((1 + r/n)nt − 1) ÷ (r/n)]. Contributions are assumed at the end of each period. If the rate is 0, the result is simply starting cash plus all contributions.

Questions

Are contributions at the beginning or end of each period?

At the end of each period, which is the common ordinary-annuity assumption.

Does this account for inflation or tax?

No. The result is a nominal future value before tax and inflation.
