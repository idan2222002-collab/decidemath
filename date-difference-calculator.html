Date difference calculator

Count how many days, weeks, and hours separate two calendar dates.

How to use: pick a start date and an end date. Turn on “include both dates” if you want a count that includes the first and last day (useful for trip length or leave days). The result is based on calendar dates, not clock times.

How the day count works

The tool subtracts the start calendar date from the end date in whole days, ignoring time zones and daylight-saving shifts. The inclusive option adds one day so both dates are counted. If the end date is earlier, the same gap is shown in reverse.

Questions

Is 1 January to 2 January one day or two?

Without the inclusive option it is 1 day between them. With the option turned on, both dates are counted, so the result is 2.

Does this use business days only?

No. Weekends and holidays are included. The result is a raw calendar count.
